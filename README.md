# 弹幕阅片

局域网里的视频审片工具。剪辑师把片子传进来，把地址发给同事，谁都能**暂停在任意一帧发弹幕**，也能用**画笔圈住一段连续帧**画重点。

原生 Node，零运行时依赖，不打包、不构建，`node server.js` 就能跑。

## 启动

```bash
node server.js          # 默认 5280 端口
PORT=5281 node server.js
```

也可以双击启动脚本（macOS 用 `.command`，Windows 用 `.bat`），与其它项目的启动脚本是同一套模板。

### 多个组各用一套

一份代码可以同时跑几个组，每个组一个启动脚本，端口和数据目录分开，片库、弹幕、报告互不相通：

| 启动脚本 | 端口 | 数据目录 | 页面显示 |
| --- | --- | --- | --- |
| `启动弹幕阅片-品牌组.command` / `.bat` | 5280 | `data/brand/` | 弹幕阅片 · 品牌组 |
| `启动弹幕阅片-短视频组.command` / `.bat` | 5281 | `data/short/` | 弹幕阅片 · 短视频组 |

两个可以同时开着，把各自的地址发给对应的组即可。要再加一个组，复制一份脚本，改掉开头的 `port`、`data_dir`、`group_name`（`.bat` 里是 `PORT`、`DATA_DIR`、`GROUP_NAME`）就行，数据目录第一次启动时自动建好。

对应的环境变量，命令行直接跑也一样：

```bash
DATA_DIR=data/short PORT=5281 GROUP_NAME=短视频组 node server.js
```

- `DATA_DIR`：数据目录，相对路径按项目根目录算；不设就是 `data/`。
- `PORT`：端口，默认 5280。
- `GROUP_NAME`：组名，显示在页面标题和左上角「弹幕阅片 · 组名」；不设就只显示「弹幕阅片」。
- `PUBLIC_ORIGIN`：分享预览图用的站点根地址。不设就按当前请求的 Host 自动拼；反代把 Host 传错时再设，见下文。

双击时终端可能没有 node（Finder 给的 PATH 只有 `/usr/bin:/bin`），所以脚本会自己按顺序找：
`PATH` → Homebrew → `/usr/local` → Volta → nvm → Codex / ChatGPT 桌面端自带的运行时 → WorkBuddy 里的 `~/.workbuddy/binaries/node/versions/*/bin/node`。
每个候选都会真跑一次并检查 Node 主版本 ≥ 18，坏掉的软链会被跳过。脚本还会顺手做几件事：已经在跑就不再重复启动（直接把地址打开）、端口被别的程序占了会明确告诉你、起来之后自动打开浏览器、关掉窗口就停服务。

启动后终端会打印本机和局域网地址，把 `http://<局域网 IP>:5280`（短视频组是 5281）发给同事即可。

**先署名**：顶栏的「署名」框是必填的。没填时它会黄色高亮，发弹幕、画标注、上传视频都会被拦下来并把你带回这个框。名字存在浏览器本地，下次打开自动带出来。

## 分享预览（OG 图）与更换域名

把首页链接发到微信、飞书时，对方看到的预览图是 `public/assets/og.png`（1200×630）。

`og:image` 不写死域名。打开页面时，服务端按这一次请求拼出绝对地址再写进 HTML：有 `X-Forwarded-Host` 就用它（多个时取第一个），否则用 `Host`；协议看 `X-Forwarded-Proto`，没有就按连接本身（本机直连一般是 `http`）。视频页是 `/#/v/<id>` 这种哈希路由，井号后面的部分爬虫不会单独来取，读到的仍是首页 HTML，所以只给首页配这张图即可。

换域名或端口时通常不用改代码，预览地址会跟着当前访问地址变。如果前面有反代或网关，传过来的 Host 不对（图指向了内网地址或错误端口），启动时指定根地址，写法和 `DATA_DIR`、`PORT`、`GROUP_NAME` 一样：

```bash
PUBLIC_ORIGIN=http://新域名:端口 node server.js
```

例如 `PUBLIC_ORIGIN=http://review.example.com:5280`。只接受 `http://` 或 `https://` 加主机和端口，末尾斜杠会被去掉。

微信等平台会缓存预览。换了 `og.png` 或域名之后，可能要过一段时间才会看到新图。

## 怎么用

1. 点右上角「上传视频」选片（或直接把视频拖进窗口）。上传前必须填署名人——报告里要写清每条意见是谁提的。建议 H.264 编码的 `.mp4`，浏览器兼容性最好。
2. 播放时暂停在要说的那一帧，在底部输入框写评论，回车发送 —— 所有人都能在这一帧看到这条弹幕。弹幕播到时间点直接在画面上方的车道里出现（不从右侧划入；同时在场的多条左对齐、从上往下叠），停几秒后淡出；暂停时原地定住。
3. 点「画笔」进入标注模式：
   - 默认从当前帧起框 6 帧，用「入点」「出点」旁的 ◀ ▶ 逐帧调，或播放到某帧按「设入点 / 设出点」。
   - 直接在画面上圈画，选颜色、撤销、清空。
   - 「预览」会播放这一段，「保存标注」后，这一帧区间内所有人都能看到你画的东西。
4. 播放条上的「截取当前帧」（或按 `S`）按视频原始分辨率存一张 PNG：画面连同当前可见的弹幕、画笔笔迹，左上角带时间码和帧号水印。
5. 右侧列表按时间排好所有弹幕和标注，点一条就跳到那一刻。时间轴上的黄点是弹幕、红条是画笔区间。点一下红条（或侧栏里的标注）选中它，两端会出现手把：拖左边改入点、拖右边改出点，按帧吸附、画面跟着停到那一帧，松手自动保存并同步给所有人（至少 1 帧、最长 12 秒；和删除一样，不限作者）。
6. 右侧列表里每条弹幕和画笔标注都有「回复」：任何人都能在别人的意见下补充（回车发送，只能删自己的回复）。弹幕的回复会缩进、小一号地跟着原弹幕一起出现在画面上（最多显示最近 3 条），截图里也会带上；有回复的画笔标注播到它的区间时，也会在弹幕区弹出「✎ 作者（画笔）」气泡并挂上回复，暂停时一样定住、列在下方卡片里。两种回复都会写进审片报告（含 .md 和复制文本）。

多人同时打开会实时同步：谁发的弹幕、谁画的圈、谁把哪条勾成「已改」，几秒内出现在其他人屏幕上，右上角显示当前在看的人数。

## 审片报告

审完一轮，点侧栏上方的「生成审片报告」：所有弹幕和画笔按时间码排成一张逐条清单，每条带一个「已改」勾选框。

- 点时间码跳回那一帧对照着改，改完回来勾上。
- 每个画笔标注都附一张起始帧截图（入点那一帧的画面 + 笔迹），打印和「下载 .md」里都带着（.md 里是内嵌图片）；「复制文本」只带文字。
- 顶部进度条和「已改 / 待改」计数实时更新；勾选状态存在服务端，几个人可以分头核，刷新也不丢。
- 「仅未处理」只看还没改的；「复制文本」直接粘进飞书/微信，「下载 .md」存成文件，「打印」出的 PDF 只有报告本身（白底黑字，没有界面的深色背景）。

## 快捷键

| 键 | 作用 |
|---|---|
| `空格` | 播放 / 暂停 |
| `←` `→` | 后退 / 前进一帧（`Shift` 加大到 1 秒） |
| `D` | 进入 / 退出画笔模式 |
| `I` `O` | 把当前帧设为入点 / 出点 |
| `Z` | 撤销上一笔 |
| `F` | 全屏 |
| `S` | 截取当前帧（带弹幕、笔迹和时间戳水印） |
| `Esc` | 关闭弹窗 / 退出画笔 |

播放条上的「帧率」不需要手填：第一次播放时自动量出来（徽章显示「自动」）。它决定逐帧步进走多远、画笔区间默认几帧、报告里写「第 N 帧」——识别不准时可以直接改，改完徽章变「手动」，不会再被自动值改回去。

## 实现要点

- **视频流式播放**：`GET /api/videos/:id/file` 支持 `Range`，拖进度条不会整段重下。
- **实时同步**：`GET /api/events` 是 SSE 长连接，上行用普通 `POST`。没有 WebSocket 依赖。
- **存储**：全部状态在 `<DATA_DIR>/db.json`（各组各一份），写入走临时文件 + rename，重启不丢。数据量到几万条再考虑换 SQLite。
- **画笔坐标**：统一存 0~1 的归一化坐标，所以换屏幕、换窗口大小、全屏，圈都落在同一位置。
- **帧率自动识别**：播放时用 `requestVideoFrameCallback` 采样相邻帧的 `mediaTime` 差值，取**中位数**换算成帧率（中位数能吃掉偶发掉帧），再归到 23.976 / 24 / 25 / 29.97 / 30 / 50 / 59.94 / 60 等标准值。结果回写服务端，所有人对「一帧」的理解一致。识别不准可以手动改，改过之后打上 `fpsSource: manual`，不再被自动值覆盖。
- **上传**：前端用 XHR 直传文件本体（自定义 header 带文件名/时长），服务端原样落盘，不解析 multipart。

## 当前限制（MVP 有意不做）

- 没有登录和权限：局域网内谁都能发、能删任意弹幕。按「内网可信」假设设计。
- 只能整支上传，不做版本对比（v1/v2 切换）。
- 逐帧精度受浏览器 `currentTime` 限制，关键帧密集的片子比较准，长 GOP 的片子步进会有偏差。
- 画笔标注最长 12 秒（`lib/config.js` 里 `maxAnnotationSpan` 可改）。
- 单文件上限 4GB（`MAX_UPLOAD_BYTES` 可改）。
